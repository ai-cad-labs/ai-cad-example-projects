# Constraints: stem

## Functional Requirements
- Connect the base to the socket housing.
- Must be hollow to allow the power cord to pass through.

## Dimensions
- Overall: 250mm length x 15mm outer diameter.
- Inner bore: 9mm diameter (for M12 external thread and cord passage).
- Threads: M12x1.5 external threads on both ends, 15mm long.

## Features
- Hollow cylindrical tube.
- External threads on both ends.

## Interfaces
- Connects to `base` via M12x1.5 thread.
- Connects to `socket_housing` via M12x1.5 thread.

## Manufacturing
- Primary process: Hollow tube stock
- Material class: Aluminum 6061
- Secondary processes: Threading
