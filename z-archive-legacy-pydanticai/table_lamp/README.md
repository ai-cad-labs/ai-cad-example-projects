# table_lamp

> Built with: PydanticAI (legacy/predecessor) · Parts: 5 · Exports: STEP + STL · DFA + DFMA

**What it is.**
A desk table lamp:
a weighted circular base (rubber-pad recess underneath), a stem/neck pipe,
a socket housing, a cylindrical shade/diffuser that seats onto the housing,
and an Edison E26-base bulb modeled as a solid of revolution for reference.
Everything is designed for CNC milling except the bulb, which is visualization-only.

**What it demonstrates.**
A five-part build with 54 render PNGs,
plus a full design-for-assembly and design-for-manufacturing pass.
A strong demonstration of the system handling a consumer-product assembly
with mixed manufacturing intents.

**How to read.**
`goals.md` → `design_plan.md` → `design_log.md`
→ per-part geometry, renders, and exports under `assembly/`
→ full agent trace in `table_lamp.log`.
